# Flood Guard 365 — HTML & CSS Website

A responsive, static website built with **plain HTML and CSS**. It does not require Next.js, React, Node.js, or a build step.

## Files
- `index.html` — page content and all sections
- `styles.css` — responsive layout, colours, typography, cards, tables, and mobile navigation
- `images/` — add your own project, team, or system screenshots here

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.

## Customise
- Update the sample milestone dates and status labels in `index.html`.
- Replace team and supervisor placeholders with real details.
- Replace document and presentation placeholder links (`href="#contact"`) with the actual file URLs.
- Change the sample email in the contact form action from `your-email@example.com` to your project's email. The form uses `mailto:` and opens the visitor's email app; it does not send messages through a server.
- Add images to the `images/` folder and use paths such as `<img src="images/team-photo.jpg" alt="Flood Guard 365 team">`.
- The map-style hero graphic is made with CSS/SVG as a conceptual illustration. It does not display live flood sensor data.

## Navigation
Home, Domain, Components, Milestones, Documents, Presentations, About Us, Contact Us.

The mobile navigation uses a CSS checkbox toggle, so no JavaScript is needed.
